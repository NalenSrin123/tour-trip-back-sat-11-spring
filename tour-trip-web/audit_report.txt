=== 1) PublicLayout.tsx ===

File: src/layouts/PublicLayout.tsx (297 lines)

Lines: Header behavior (81-208), Mobile menu (200-234), Footer (242-283)

Exact observations by 360-390px widths (common mobile)

- Header container: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8 flex items-center justify-between (L81). At 360-390px: px-4 gives 16px padding on sides; sm:px-6 doesn't kick in until sm (640px) — OK for small phones.

- Logo + actions spacing: flex with gap-2 on logo (L82), gap-4 on right actions (L102). Mobile menu button md:hidden (L201-207). Desktop nav hidden on < md (L88). Right action group hidden on < md (L102) — so on 360-390px only logo + hamburger visible. Spacing is adequate.

- Desktop links hidden on mobile: L88 uses hidden md:flex — YES. All nav links (Home/Tours/Destinations/About/Contact + Admin Portal conditional) hidden < md.

- Right actions hidden on mobile: L102 hidden md:flex — includes ThemeToggle (L103-106), notifications (L108-114), user dropdown (L116-177), or Sign In/Up (L179-197). ThemeToggle appears in mobile menu at L219 — that’s good.

- Auth buttons on mobile: mobile menu shows Sign In/Sign Up side-by-side in div with lex flex-gap gap-3 (L227) and w-1/2 each (L228-229). Note lex-gap is non-standard in Tailwind v3; in Tailwind v4 gap-* on flex container is fine — lex-gap is likely a typo/unused class (should be just lex gap-3). Also buttons use w-1/2 which can be tight on very small screens but OK for 360-390px.

- Mobile menu coverage: menu is md:hidden absolute top-full left-0 right-0 ... (L210-233) — drops below header, full width, vertical stack. Covers all nav links (L212-216). Includes ThemeToggle (L217-221), auth-specific items (L221-231). Does it cover 'all nav links' that exist in desktop? Yes (Home/Tours/Destinations/About/Contact). Admin Portal link missing from mobile menu (desktop has it at L94-99 when user.role===ADMIN). This is an omission.

- Mobile menu closes on route change: Links call onClick={() => setMobileMenuOpen(false)} (L212-216,223,228-229). However there is no useEffect watching location.pathname to auto-close menu on navigation (no such effect present). Closing via link click works for in-app Link clicks; programmatic navigation or some cases still rely on click — but better to close on route change. Currently NOT auto-closing on route change via effect.

- Mobile menu has backdrop/overlay? No backdrop element. Menu is positioned below header (absolute top-full) — no overlay div behind it; content below can still be interacted with visually but menu is on top (z-50 header). No overflow-hidden on body when open. Also menu does not scroll internally if very long (no max-h, overflow-y-auto).

- Mobile menu scroll behavior: py-4 px-6 space-y-4 (L211) — no max-height or overflow-y-auto; on small viewports with logged-in state it could grow but usually fine. No body scroll lock.

- Footer responsiveness: grid grid-cols-1 md:grid-cols-4 gap-10 (L244). On mobile stacks to 1 col; padding px-4 sm:px-6 lg:px-8 (L244,280). Margin mt-20 (L243). Looks OK. Text wraps naturally. No horizontal overflow obvious.

- Elements hidden on mobile: Desktop-only groups use hidden md:flex (nav L88, right actions L102). ThemeToggle present in mobile menu. Search bar in Home (L118-164) is inside md:flex-row form — stacks to column on mobile (good). No other major hidden elements except admin-only links.

- Severity notes: Minor issues — missing Admin link in mobile menu; no route-change auto-close; no backdrop/body scroll lock; lex-gap typo (non-standard) at L227; mobile menu doesn’t close on programmatic navigation via location change.


Suggested Tailwind fixes (PublicLayout):
- Add effect: useEffect(() => setMobileMenuOpen(false), [location.pathname]) to auto-close on route change.
- Add backdrop + body scroll lock when open (e.g. fixed overlay behind menu, overflow-hidden on body).
- Make mobile menu scrollable: max-h-[calc(100vh-4rem)] overflow-y-auto on the dropdown.
- Include Admin Portal in mobile menu when user.role==='ADMIN'.
- Replace lex flex-gap gap-3 with lex gap-3 (L227).
